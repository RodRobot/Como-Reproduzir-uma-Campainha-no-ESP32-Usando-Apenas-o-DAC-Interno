🔔 Como Reproduzir uma Campainha no ESP32 Usando Apenas o DAC Interno

Este projeto demonstra como reproduzir o som de uma campainha utilizando apenas o DAC (Conversor Digital-Analógico) interno do ESP32, sem a necessidade de módulos MP3 ou conversores DAC externos.

O objetivo é mostrar como o ESP32 pode gerar sinais analógicos capazes de reproduzir pequenos efeitos sonoros, sendo uma excelente introdução ao funcionamento do DAC e ao processamento de áudio em microcontroladores.

🚀 Recursos
Utiliza somente o DAC interno do ESP32
Não requer DFPlayer Mini ou DAC externo
Geração de áudio diretamente pelo GPIO25
Código simples e fácil de entender
Ideal para iniciantes em ESP32
Excelente exemplo para estudar sinais analógicos
🛠 Componentes Utilizados
ESP32 DevKit
Amplificador PAM8403 (opcional, porém recomendado)
Alto-falante de 8 Ω
Protoboard
Jumpers
🔌 Ligações
ESP32	Componente
GPIO25	Entrada de áudio do PAM8403
GND	GND do PAM8403
5V	Alimentação do PAM8403
